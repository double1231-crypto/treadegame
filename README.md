# 🌍 무역 문명 게임 (초등 6학년 사회)

학생(또는 모둠) 2~30팀이 각자 나라를 맡아 자원을 무역하고 마을 → 도시 → 왕국 → 제국으로 발전시키는 실시간 수업용 게임입니다.
설치·로그인 없이 브라우저만 있으면 됩니다.

## 내 컴퓨터에서 먼저 시험해 보기
`index.html` 을 더블클릭해서 열면 **동작하지 않아요** (브라우저가 파일 주소에서는 게임 스크립트를 막아요).
대신 **`실행하기.bat`** 을 더블클릭하세요. 작은 서버가 켜지고 첫 화면(`http://localhost:8123/`)이 열려요.
검은 창을 닫으면 서버가 꺼져요. 학생 태블릿은 이 주소로 들어올 수 없으니, 수업에서는 GitHub Pages 주소를 쓰세요.

**혼자 전체 흐름을 시험하려면** 첫 화면 아래 「🧪 이 컴퓨터에서 혼자 시험해 보기」(`test.html`)를 누르세요.
선생님 화면과 학생 화면 2~4개가 한 페이지에 함께 떠요. 인터넷·WebRTC 없이 이 컴퓨터 안에서만 움직이는 테스트 모드라
보안 프로그램이나 네트워크가 연결을 막아도 시험할 수 있어요. (GitHub Pages 주소에서도 `.../test.html` 로 쓸 수 있어요)

## 수업에서 쓰는 법
1. **선생님 PC**: `host.html` 을 열면 방 번호(4자리)가 나옵니다. 화면을 프로젝터로 띄워 두세요.
2. **학생 태블릿**: `play.html` 에 들어가 방 번호 입력 → 나라 이름(8자)·국기·색깔 정하기.
   나라 수는 선생님 화면 「참가한 나라」 옆 −/＋ 로 2~30개 사이에서 정해요 (처음은 6개).
3. 선생님 화면에서 이름 확인 후 **승인**(필요하면 「이름 수정」) → **게임 시작**.
4. 진행: 준비 2분 → 6라운드 × (자원 생산 → 미니게임 1분 → 무역·건설 3분 30초 → 사건 카드 10초). 전체 30분.
   2·5라운드에는 🤝 협동 프로젝트(📱 스마트폰, 🔋 전기차 배터리), 3·6라운드에는 🏗️ 국제 입찰(🌉 다리, ⚓ 항만)이 열려요.
   타이머가 끝나면 자동으로 넘어가고, 「다음 단계」·「일시정지」·「+30초」로 조절할 수 있어요.
5. 「무역 금지」·「전쟁 금지」·「발전 공지」 스위치로 상황을 바꿔 볼 수 있어요.
6. 게임이 끝나면 나라별 1인당 GDP 그래프와 순위, 무역·원조·전쟁 횟수 표가 나옵니다.
7. 게임 중 현황판 맨 위에 **🏆 1인당 GDP 순위 띠**가 떠요 (순위가 바뀌면 ▲▼ 표시).
8. **🎤 라운드 하이라이트**: 라운드가 끝날 때마다 선생님 화면에 「쑥쑥 성장·무역 부지런·최고의 거래·따뜻한 나눔·발전 성공·퀴즈 척척·비밀 임무 성공」이 크게 떠요.
9. **🕵️ 비밀 임무** (⚙️ 설정에서 끄고 켤 수 있어요): 라운드마다 나라별로 몰래 임무가 생겨요(예: 무역 3번, 서로 다른 나라 2곳과 무역, 수입 5개).
   학생 「무역」 탭 맨 위에 진행 막대가 보이고, 성공하면 바로 1인당 GDP +100만 원.
10. **🏁 GDP 레이스 + 🏅 칭찬 배지**: 게임이 끝나면 라운드별 1인당 GDP 막대 경주가 자동으로 나오고(결과 화면에서 다시 보기),
   모든 나라가 칭찬 배지를 하나씩 받아요 (👑 GDP 1등, 🤝 무역왕, 🌐 친구가 많은 나라, 😇 나눔 천사, 🎯 퀴즈 박사, 🚢 수출 대장,
   🛍️ 수입 대장, 🏭 공장장, 🏗️ 건축가, 🕵️ 비밀 요원, 🚀 역전의 명수, 🕊️ 평화 지킴이 …). 학생 태블릿에도 우리 나라 배지가 크게 떠요.

## 선생님 화면에서 할 수 있는 것
- **⚙️ 게임 설정** (참가 대기 화면 오른쪽): 게임 길이 20분/30분/40분, 미니게임 문제 세트, 기능 켜고 끄기
  (미니게임·사건 카드·공장·세계 과제·원조·전쟁·기능 하나씩 열기·효과음).
- **📖 튜토리얼**: 참가 대기·준비 시간에 「📖 튜토리얼」을 누르면 게임 방법 슬라이드가 선생님 화면에 크게 떠요.
  ◀ ▶(또는 키보드 화살표)로 넘기고, 「건너뛰기」(또는 Esc)로 언제든 닫아요. 그동안 학생 태블릿에는 「📺 선생님 화면을 봐요」가 떠요.
  끄고 켠 기능에 맞춰 슬라이드가 바뀌어요.
- **📱 학생 각자 튜토리얼**: 학생이 나라를 만들면 자기 태블릿에 짧은 게임 방법(8장 안팎)이 한 번 떠요.
  우리 나라에 많은 자원·없는 자원을 직접 보여 주고, 켜 둔 기능만 설명해요. 손가락으로 밀거나 ◀ ▶로 넘기고 「건너뛰기」로 닫아요.
  학생 화면 나라 이름 옆 **📖 방법** 버튼으로 언제든 다시 볼 수 있고, 선생님이 「📱 태블릿에서 각자 보기」를 누르면 모두의 태블릿에 다시 떠요.
- **🧪 직접 해 보기 (연습)**: 튜토리얼 마지막 장이나 승인 대기 화면의 버튼으로 시작해요. 태블릿 안에서만 돌아가는 연습 게임에서
  🤖 연습나라 2곳과 **진짜 화면 그대로** ① 무역 제안 보내기 → ② 받은 제안 수락하기 → ③ 발전하기를 해 봐요.
  아래쪽 코치 안내가 한 단계씩 알려 주고, 끝나면 「진짜 게임으로 돌아가기」. 진짜 게임에는 아무 영향이 없어요.
  게임 시작 전·준비 시간에만 할 수 있고, 미니게임이 시작되면 저절로 진짜 게임으로 돌아가요.
- **🔓 기능이 하나씩 열려요**: 1라운드 무역 → 2라운드 🏭 공장·🌐 세계 과제 → 3라운드 🎁 원조 → 4라운드 ⚔️ 전쟁. 열릴 때 안내가 떠요.
- **🧰 선생님 도구**: 모든 화면에 공지 보내기, 👀 학생 화면 멈추기(타이머도 멈춤), 나라별 자원 주기·빼기.
- **📷 QR 입장**: GitHub Pages로 열면 방 번호 옆에 QR이 떠서 태블릿 카메라로 바로 들어올 수 있어요.
- **🌐 세계 지도**: 「현황판 / 영토 지도 / 세계 지도」 중 세계 지도에서 나라 사이 무역로(굵을수록 많이)·원조·전쟁과 📊 시장 시세판을 봐요.
- **🎵 배경음악** (선생님 화면 왼쪽 아래): 켜기/끄기·소리 크기. 화면을 한 번 누르면 시작해요.
  참가 대기·준비(잔잔한 항구) → 미니게임(빠르게, 마지막 10초 째깍째깍) → 무역(경쾌하게) → 세계대공황(어둡게) → 게임 끝(팡파르).
  효과음이 나면 음악이 잠깐 작아지고, 튜토리얼·일시정지·화면 멈춤 때는 작게 나와요. 학생 태블릿에서는 나오지 않아요.
  원하는 음악이 있으면 `music` 폴더에 `lobby.mp3`, `minigame.mp3`, `trade.mp3`, `crisis.mp3`, `end.mp3` 를 넣으세요
  (있는 파일만 바뀌어요). GitHub에 올리는 음악은 공개되니 공유마당·YouTube 오디오 보관함 같은 **저작권 걱정 없는 음악**을 쓰세요.
- **💬 되돌아보기 + 📥 결과 내려받기**: 게임이 끝나면 학생 태블릿에 질문 3개가 뜨고 답이 선생님 화면에 모여요.
  「결과 내려받기(엑셀)」로 나라별 GDP·무역·원조·수출입·되돌아보기 답을 CSV로 저장해요.

## 점수와 평화
- **💵 1인당 GDP (점수, 원)**: 처음 1,000만 원. 라운드마다 발전 단계에 따라 벌고(마을 100만 원 → 제국 700만 원),
  무역에 성공하면 두 나라 모두 +150만 원, 미니게임 정답 1개당 +50만 원(1등 +100만 원, 협동 성공 +100만 원).
  (`js/config.js` 숫자 1 = 1만 원. 1년 기준으로 설명하면 자연스러워요. 실제 우리나라 1인당 GDP는 1년에 약 5,000만 원이에요)
- **🌍 비슷한 나라**: 1인당 GDP가 정해진 단계를 넘을 때마다 학생 태블릿에 「이제 중국과 비슷해요!」처럼 알려 줘요.
  태국(시작, 1,000만 원) → 브라질 1,400만 → 중국 1,750만 → 칠레 2,300만 → 폴란드 3,000만 → 포르투갈 3,900만 → 일본 4,500만
  → **대한민국 5,000만** → 프랑스 6,400만 → 독일 7,600만 → 미국 1억 1,800만 원 (마지막 단계).
  학생 화면 GDP 아래와 선생님 현황판 카드에 지금 비슷한 나라가 늘 보여요. 값은 2024년 무렵의 대략적인 수치예요 (`js/config.js` 의 `GDP_COMPARE` 에서 고칠 수 있어요).
- **🎁 원조 / 🙏 도움 요청**: 무역 탭에서 대가 없이 자원을 보내거나, 부족한 자원을 다른 나라에 부탁할 수 있어요.
  무역 금지 중에도 할 수 있어요.
- **🕊️ 세계 평화 점수** (선생님 화면에만 보여요, 처음 60점): 무역 성공 +3, 원조 +5, 무역 거절·실패 −2, 전쟁 −15.
  **30점 밑으로 떨어지면 📉 세계대공황** → 모든 나라 생산량이 절반이 되고 모든 화면에 알림이 떠요. 40점 이상으로 오르면 회복돼요.
- **🏭 공산품** (🚗 자동차, 💾 반도체): 「영토·건설」 탭 공장에서 원료로 만들어요. 다른 나라에 수출하면 GDP가 크게 오르고,
  수입한 나라도 조금 올라요. 🔬 기술 나라(나라의 약 1/3)는 원료가 덜 들어요 → 교과서 100~101쪽(원료를 수입해 상품을 만들어 수출).
- **🤝 협동 프로젝트 / 🏗️ 국제 입찰** → 교과서 106~107쪽(상호 의존과 경쟁). 프로젝트는 3개 나라 이상이 자원을 모아야 완성,
  입찰은 자원을 가장 많이 건 나라가 낙찰(진 나라는 돌려받음).
- **🧱 관세 사건 카드**(108쪽)와 **⚓ 무역항 나라**(104쪽 싱가포르, 다른 나라끼리 무역할 때마다 수수료)도 있어요.
- **게임 끝 화면**의 「📚 우리가 게임에서 한 일 → 교과서 낱말」 카드와 나라별 주요 수출품·수입품 표로 94쪽 수업을 시작해 보세요.
- 숫자는 모두 `js/config.js` 의 `GDP`, `PEACE`, `GOODS_INFO`, `PROJECTS`, `BIDS`, `WORLD_TASKS` 에서 바꿀 수 있어요.

## 문제 고치기
`questions.json` 을 메모장으로 열어 고치면 됩니다.
- 지금 문제는 6학년 2학기 사회 1단원 「세계의 자연환경」 교과서에서 냈어요.
- `games` 순서대로 라운드마다 하나씩 나옵니다 (1R 지형 경관 → 2R 산지·하천 → 3R 해안 → 4R 기후 분포 → 5R 기후와 생활 OX → 6R 협동).
- 문제 하나 = `q`(문제), `choices`(보기), `answer`(정답 보기 글자 **그대로**), `explain`(해설). 줄바꿈은 `\n`.
- `settings` : 한 번에 나오는 문제 수, 참여 보상, 정답당 보상, 1등 보너스.
- 협동 미션: `goalPerCountry`(나라당 목표 정답 수) × 나라 수 = 전체 목표, `reward` = 성공 시 전원 보상.

게임 규칙 숫자(발전 비용, 생산량, 시간, 전쟁 손실률 등)는 `js/config.js`, 사건 카드는 `js/events.js` 에 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (`.nojekyll` 포함).
2. 저장소 **Settings → Pages → Branch: main / (root)** 저장.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
   선생님은 `.../host.html`, 학생은 `.../play.html`.

  학교 와이파이·LTE 어디서나 들어올 수 있어요. 아래 「Firebase 연결하기」를 보세요.
- 설정이 비어 있으면 PeerJS(WebRTC)로 기기끼리 직접 연결해요. 서로 다른 네트워크(학교 와이파이 ↔ LTE)에서는
  「방은 찾았는데 연결이 열리지 않아요」가 뜨며 안 될 때가 많아요. (`?net=peer` 를 붙이면 PeerJS를 강제로 써요)
- 통신 코드는 `js/net.js` 한 파일에만 있어요.

## Firebase 연결하기 (처음 한 번, 5분)
1. https://console.firebase.google.com 에 Google 계정으로 들어가 **프로젝트 만들기** (이름 예: `trade-game`, Google 애널리틱스는 꺼도 돼요).
2. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 **싱가포르(asia-southeast1)** → **잠금 모드로 시작** → 사용 설정.
3. **규칙** 탭의 내용을 모두 지우고 아래를 붙여 넣은 뒤 **게시**:
   ```json
   {
     "rules": {
       "rooms": {
         "$room": { ".read": true, ".write": true, ".validate": "$room.matches(/^[0-9]{4}$/)" }
       }
     }
   }
   ```
4. **프로젝트 개요(톱니바퀴) → 프로젝트 설정 → 내 앱 → 웹(`</>`) 아이콘** → 앱 닉네임 입력 → 앱 등록.
   나오는 `firebaseConfig = { ... }` 의 `{ ... }` 부분을 복사해요. (`databaseURL` 줄이 있는지 확인)
5. `js/firebase-config.js` 의 `export const firebaseConfig = null;` 에서 `null` 을 복사한 `{ ... }` 로 바꾸고 GitHub에 다시 올려요.
- 무료 요금제(Spark)로 써요. 한 달 내려받기 무료량은 10GB이고, 30명이 30분 하면 대략 1~2GB(추정)라 한 달에 몇 번 수업할 수 있어요.
  사용량은 Realtime Database의 **사용량** 탭에서 볼 수 있어요.
- 설정값(apiKey 등)은 웹사이트에 공개돼도 되는 값이에요.
- 🧹 선생님 화면을 닫으면 그 방의 메시지가 서버에서 자동으로 지워지고, 새 방을 만들 때 이 컴퓨터가 전에 쓰던 빈 방도 지워요.
- 시험용: 주소 끝에 `?net=local` 을 붙이면 인터넷 없이 한 컴퓨터의 여러 탭으로 시험해 볼 수 있어요
  (예: `host.html?net=local`, `play.html?net=local&room=1234`).
